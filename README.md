# Kingpost Floor (Grok)

Charcoal command center. Separate from Dunder Mifflin (Claude).

## Install on the shop PC

1. You need **Node.js LTS** once: https://nodejs.org
2. On this page click green **Code** → **Download ZIP**
3. Unzip next to KingpostJim so you have:
   - `C:\\Users\\1951\\Kingpost-Floor-main`
   - `C:\\Users\\1951\\KingpostJim`
4. Open the Floor folder. Double-click **Start Floor**.
5. First run takes a few minutes (`npm install`). A browser opens.
6. Leave that black window open while you use Floor.

It reads Jim’s queue in KingpostJim. Approve writes the same file Dunder Mifflin uses.

Run one Floor for Approve at a time if both apps are open.
