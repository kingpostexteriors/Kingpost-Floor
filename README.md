# Kingpost Floor

Shop command center for Jim / Hermes.

## Get it on the shop PC

1. On this GitHub page, click the green **Code** button.
2. Click **Download ZIP**.
3. Unzip it next to KingpostJim so you have:
   - `C:\\Users\\1951\\Kingpost-Floor-main`
   - `C:\\Users\\1951\\KingpostJim`
4. Open the Floor folder and double-click **Start Floor**.
5. First time only: if a Node.js page opens, install **LTS**, then double-click **Start Floor** again. That first run can take a few minutes.
6. Leave that window open while you use Floor.

Approve / Reject in Floor writes the same queue file `send_approved.py` already uses.
